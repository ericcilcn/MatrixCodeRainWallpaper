### About

Matrix Code Rain Wallpaper is a lightweight real-time web wallpaper for Wallpaper Engine. It recreates the fixed-grid Matrix-style code rain look with local HTML, CSS, JavaScript, and bundled fonts instead of a large video file.

The project focuses on visual accuracy, low file size, adjustable settings, audio spectrum response, and smooth performance across desktop resolutions.

Support is completely optional. The wallpaper remains free. Tips help cover the time spent on testing, visual tuning, audio response improvements, documentation, and future updates.

### 主页介绍

Matrix Code Rain Wallpaper 是一个为 Wallpaper Engine 制作的轻量级 Web 动态壁纸。

它不使用录屏视频，而是用本地 HTML、CSS、JavaScript 和字体文件实时渲染代码雨，所以文件体积更小，也可以在 Wallpaper Engine 里调整字体、亮度、时钟、音频示波器等选项。

这个项目的目标是尽量还原 Matrix 风格的固定网格代码雨，同时保持性能、可调节性和简洁的安装方式。

赞助完全自愿。壁纸本体保持免费。你的支持会用于后续调试、视觉细节调整、音频响应优化、文档整理和更多设备测试。

谢谢你使用这个壁纸。
